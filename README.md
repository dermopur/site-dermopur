# Dermopur – site d'Indie Coudret

Site du cabinet de maquillage semi-permanent Dermopur (Saint-Jean-le-Blanc, près d'Orléans).

- Pour modifier les prix, les prestations, le planning ou les photos : lire **[GUIDE.md](GUIDE.md)**.
- Les fichiers à modifier sont dans `mes-contenus/` ; les photos vont dans `photos/`.
- Site statique (HTML, CSS, JavaScript), sans installation : il suffit d'ouvrir `index.html` ou de l'héberger sur GitHub Pages.
